The Complete Concept Map

Every idea in machine learning for biology, labeled by what kind of thing it is

Machine learning terms get confusing because they belong to different kinds of categories that are usually listed together. This page sorts them. The colors show what kind of thing each idea is:

Color Kind of thing The question it answers Example
red Paradigm What does my training data look like? Supervised
orange, dashed Hybrid paradigm A mix of two paradigms Self-supervised
blue Task What kind of answer do I want? Classification
green Method / model family What machine produces the answer? Random forest
yellow Pipeline step A choice every project makes Loss function
white Option One possible answer to a pipeline choice Ridge (L2)
purple Strategy / approach A way of working that cuts across paradigms Transfer learning
grey Math tool The math underneath Hessian
