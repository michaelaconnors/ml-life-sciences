Filtering patients

Two columns decide who is usable. Neither can be a feature — both are known only after treatment — but they can select rows:

  • Reached a stable dose. If a patient never settled, their recorded dose is not a trustworthy target.
  • Dose actually recorded. No \(y\), nothing to learn from.

Imputing height and weight

Height is missing for 19% of patients and weight for 5% — too many to drop. Both are filled with the training median.

The median is a learned parameter, not a fixed constant, so it belongs to the training set. Computing it over the test set would let test patients inform each other’s predictions, and would not match deployment: a clinician with one new patient has no test set to average over. The rule for the rest of this notebook is the same every time — learn on train, apply to both.

medians = X_train_df.median()          # computed from TRAINING patients only

X_train_df = X_train_df.fillna(medians)
X_test_df  = X_test_df.fillna(medians)  # test uses the TRAINING medians

print(X_train_df.isna().sum().sum(), X_test_df.isna().sum().sum())   # both should be 0
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train_df)   # learn x̄ and s, then apply
X_test  = scaler.transform(X_test_df)        # apply the SAME x̄ and s

print(X_train.shape, X_test.shape)
print(X_train.mean(axis=0).round(3)[:3], X_train.std(axis=0).round(3)[:3])
n, p = X_train.shape

w      = np.zeros(p)     # w ∈ ℝ¹⁷
b      = 0.0             # scalar
eta    = 0.1
steps  = 2000
losses = []

for t in range(steps):
    y_hat  = X_train @ w + b              # ŷ = Xw + b1    → vector ∈ ℝⁿ
    r      = y_train - y_hat              # r = y − ŷ      → vector ∈ ℝⁿ
    losses.append(np.mean(r**2))          # L = (1/n) rᵀr  → scalar
    grad_w = -(2/n) * (X_train.T @ r)     # −(2/n) Xᵀr     → vector ∈ ℝ¹⁷
    grad_b = -(2/n) * np.sum(r)           # −(2/n) 1ᵀr     → scalar
    w      = w - eta * grad_w             # w ← w − η∇_w L
    b      = b - eta * grad_b             # b ← b − η ∂L/∂b
